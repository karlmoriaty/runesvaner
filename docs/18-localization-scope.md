---

## 1. Principles

1. **English is the only source of truth**: English documents must be complete and cover every detail, boundary, and example.
2. **Chinese/German cover the core**: only the "essential core" is translated; unnecessary details may be trimmed; word-for-word correspondence is not promised.
3. **UI is complete in three languages**: the volume of interface strings is small, so they must be fully translated; no half-Chinese/half-English or half-German/half-English text is allowed.
4. **Critical content must not be trimmed**: security, privacy, licensing, breaking changes, AOT limitations, and cost disclaimers must be fully synchronized across the three languages.
5. **Translation does not change semantics**: commands, default values, numbers, field names, and error codes must match English.
6. **Human review**: machine translation may only be used as a first draft; German must be reviewed by a native speaker, and Chinese requires technical review.

## 3. Documentation Tiers

### 3.1 L1: Full translation (core required reading)

These pages must provide complete Chinese/German versions (style adjustments are allowed; removing steps is not):

| Category | Page |
| --- | --- |
| Entry | `README.md` |
| Getting Started | Install, 5-minute quickstart, First diagnosis |
| Concepts | Diagnostic session, Request & segments, Cost ledger, Sampling, Privacy model |
| Guides | Microsoft.Extensions.AI integration, Cost configuration, Native AOT, Troubleshooting |
| Operations | Storage & retention, Security essentials |
| Contributing | Build & test, CLA |
| Reference | Configuration (top-level options), CLI (common commands) |

Standards for L1:

- Every command can be copied and executed.
- All default values, field names, and error codes match English.
- There is a "what you should see" verification step.
- There is a link to the original English text for cross-reference.

### 3.2 L2: Condensed core (keep conclusions and operations, trim explanations)

These pages provide **condensed versions** in Chinese/German, retaining:

- Conclusions and recommendations.
- Operation steps and commands.
- Key default values and limitations.
- Common errors and next steps.
- Link to the full English text.

Allowed to trim:

- Rationale derivation and design trade-offs.
- Long explanations of boundary conditions.
- Historical background and competitor comparisons.
- Multiple example variants (keep one minimal example).
- Complete property/metric tables (keep the most commonly used items).

Applicable pages:

| Category | Page |
| --- | --- |
| Reference | Public API summary, Event schema summary, Metrics summary |
| Project | Roadmap summary, Governance summary |
| Guides | Advanced sampling/budget configuration, VectorData/SK integration details |
| Operations | Long-tail troubleshooting cases |

### 3.3 L3: English only (provide a redirect)

These pages are not translated; the Chinese/German pages display:

- A one-line note: "This page is only available in the full English version because it contains a large amount of API/architecture detail."
- A link to the original English text.
- If security/breaking changes are involved, a summary and warning must exist in L1/L2.

Applicable pages:

| Category | Page |
| --- | --- |
| Reference | Complete API reference (generated by DocFX), complete metrics/properties tables, complete event schema |
| Architecture | Internal architecture, thread model, overhead budget, AOT matrix details |
| Process | All ADRs/RFCs, complete changelog, release checklist |
| Performance | Complete benchmark methodology, datasets, raw results |
| Examples | All example variants, edge scenarios |

## 4. Non-Trimmable Content

The following content must have a complete summary or the full text in Chinese/German, even if it belongs to L2/L3:

| Content | Requirement |
| --- | --- |
| Security warnings | Full translation; conditions and consequences must not be omitted |
| Privacy defaults | Explicitly state `None`, hashing, and export redaction |
| Key/Header handling | Explicitly state the fields that are never collected |
| License and CLA | Translate the key points; the official text is governed by the English/legal text |
| Breaking changes | Migration steps, impact scope, and rollback method |
| AOT/Trim limitations | Explicitly state the AOT status and fallback for SQLite/OTel |
| Cost disclaimer | Explicitly state estimation, unknown models, and price table version |
| Data retention/deletion | Explicitly state the default retention period and deletion method |

## 6. Translation Maintenance

| Rule | Notes |
| --- | --- |
| English first | Translate only after the English PR is merged; do not translate unmerged content |
| L1 synchronization | Update Chinese/German within 7 days of an English change |
| L2 synchronization | Update with the next minor version |
| L3 | Not translated; retain the redirect and security summary |
| Version labeling | Label each page top with `Based on English vX.Y` |
| Outdated notice | When the English version is updated but the translation is not, display "the translation may be outdated" |
| Terminology consistency | Use the glossary in Section 7; new terms must be added to the glossary first |
| Machine translation | First draft only; human review is mandatory |
| Legal text | License/CLA are governed by the English legal text; translations are for reference only |

## 8. Acceptance Criteria

- **AC-L1**: L1 pages are navigable in all three languages, commands can be copied and executed, and default values match English.
- **AC-L2**: L2 pages have a "full English text" link at the top and contain key default values/limitations/common errors.
- **AC-L3**: L3 pages have a language note and an English redirect; when security/breaking changes are involved, L1/L2 contain a summary.
- **AC-L4**: Security, privacy, licensing, AOT limitations, and cost disclaimers are 100% synchronized across the three languages.
- **AC-L5**: The glossary covers all high-frequency terms in the UI and documentation; new terms are added to the glossary before translation.
- **AC-L6**: Outdated translations display a notice; there must be no case where "the text looks Chinese but the commands/default values are from an old version."

---

## 9. Non-Goals

- Do not promise word-for-word translation or page-by-page correspondence.
- Do not provide full machine-translated text for L3.
- Do not translate before the English is finalized.
- Do not let translations become a legal/security basis (the English original and lawyer-reviewed text govern).
- Do not delay the English release because of translation.
